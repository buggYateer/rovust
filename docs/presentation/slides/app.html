IMPLEMENTATION · THE APPLICATION

A desktop application that shows truth and belief side by side

Mission setup — environment, strategy, localisation mode, AI, seed; remote control; map layers.

Two maps — the true world the robot never sees, and the map it builds. Click either for a large live view.

Telemetry tabs — every sensor live with one-click fault injection; the PWM → encoder → PID loop; statistics; the radio link.

Light and dark, a user guide inside (F1), mission reports, one-click installer for the team.

PyRov · Implementation · PySide6 / Qt — sim/qtui/

The application is a conventional desktop program, built with Qt. The left panel configures a mission; the two maps show ground truth and belief; the tabs below expose the inner loop — every sensor reading, the motor control loop, statistics and the radio link. Any sensor can be broken with one click while the mission runs, which is how we demonstrate the fault detector and the safety layers.

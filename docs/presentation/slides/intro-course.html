INTRODUCTION

Every lecture is a working part of the rover

LectureWhat Rovust does with it
Embedded roboticsOne on-board controller, differential drive, one 50 ms loop
Robot behaviourSubsumption with 10 layers, feedback, random walk, radio communication
Sensors 1 & 220+ sensors — sonar, IR, encoders, IMU, compass, camera — each with its real errors
ActuatorsDC motors, H-bridge, PWM, a non-linear duty → speed curve and its calibration table
ControlOn-off, hysteresis, P / PI / PID per wheel, driving straight
NavigationDead reckoning + sensor fusion, occupancy grid, A*, frontier exploration
This table is our map of the course. Each row is a lecture — actuators, encoders, control, sensors, behaviour, navigation, communication — and each is implemented as a module that the others depend on. We will go through them in that order: first the analysis of the hardware we simulate, then the design of the software on top, then the measurements.

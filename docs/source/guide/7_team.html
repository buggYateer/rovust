تشغيل البرنامج

الخلاصة

على ويندوز: تنزّل المشروع، دبل كليك على setup.bat مرة واحدة، وبعد كده run.bat.

  1. نزّل المشروعمن صفحة GitHub: Code → Download ZIP، وفك الضغط في مكان اسمه قصير زي C:\Rovust.
  2. دبل كليك على setup.batمرة واحدة بس. بينزّل Python لو مش موجود، وكل المكتبات، ويعمل shortcut، ويفتح البرنامج.
  3. بعد كده run.batأو الـ shortcut، كل مرة.
لو مشتغلش

ويندوز 11 ساعات بيمنع المكتبات لو Smart App Control شغال. اقفله وجرّب تاني.

لو بتستخدم الـ terminal

pip install -r requirements.txt
python main.py        # البرنامج
pytest                # 60 اختبار

الخلاصة

مشاكل حقيقية قابلتنا وإحنا بنبني. تنفع تتقال في المناقشة كدليل إن الشغل اتجرّب بجد.

روبوت وقع وهو راجع لورا

مكانش فيه cliff sensors ورا. ضفنا زوج ورا وزوج على الجنب.

الحيطان كانت بتتمسح من الخريطة

كنا بنعتبر «مفيش صدى» معناها فاضي. دلوقتي مفيش صدى مبيغيّرش حاجة.

الـ IR كان بيشوف عوائق مش موجودة

قراءاته قرب أقصى المدى ضوضاء. بنستخدم أول 70% بس.

الـ gyro لوحده بيلف الخريطة

20 درجة في الدقيقة. لازم يتعاير وهو واقف، ومعاه compass.

«الموبايل مش بيرد»

غالبًا الإشارة مقطوعة أو المهمة خلصت. علشان كده عملنا التنبيهات.

البرنامج كان بيتقل مع الوقت

مكتبة بتتنادى 20 مرة في الثانية كانت أبطأ حاجة. القياس هو اللي لقاها مش التخمين.

البرنامج وقع وإحنا بنسجّل الفيديو

لما الروبوت رجع يمشي لوحده بعد ما حد ساقه. اتصلّح واتعمل له اختبار.
